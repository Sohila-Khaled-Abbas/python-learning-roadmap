# Data apps with Streamlit, Plotly & Dash

Turn a tested dataset into an interface that communicates the right question.

Extension beyond the Boot.dev video

## Connect to your work

Apply this to your Python data tools, PixelFed quality work, n8n integrations or BI delivery when the project needs it.

## Learn by doing

- Choose one framework and learn its state/rerun or callback model.
- Keep transformations testable outside the UI.
- Show empty, stale and invalid-data states with accessible labels.

## Original practice

Build a read-only quality dashboard from the synthetic CLI output. Show row counts, rejects, freshness and a filterable category chart.

## Exit check

The chart reconciles to the CLI output; empty filters have a clear state; a reviewer can identify the source and limitations.

## Understand the idea

Streamlit is useful for rapidly building Python-led data interfaces. Its execution and state behavior differ from a static Power BI report. Keep expensive data loading and transformations separated from the display and learn the cache/state rules before relying on them.

Plotly provides figures; Dash adds an application model with layouts and callbacks. Choose one small workflow first. Your existing Power BI skills transfer through metric definitions, filter behavior, accessible color and clear data provenance—not through copying every dashboard interaction unchanged.
