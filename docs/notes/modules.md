## Learn by doing

- Create modules with no work on import.
- Use type hints and a dataclass for a validated record.
- Keep configuration separate from transformations.

## Original practice

Split the ledger into parsing, validation and reporting modules.

## Exit check

Importing a module performs no file writes or network calls.
