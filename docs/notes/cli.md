## Learn by doing

- Parse arguments with argparse.
- Send summary output to stdout and diagnostic logs to stderr.
- Use environment variables for credentials; never commit secrets.

## Original practice

## Exit check

A new terminal can run the tool and distinguish input failure from a valid empty result.

## Understand the idea

Make a script runnable by you, CI, or an orchestrator. n8n can call a deliberate CLI contract with visible exit status.

Work through the practice with a tiny fixture, predict the result before running it, and record one boundary case. Use the exit check as evidence before moving on.
