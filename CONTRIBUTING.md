# Contributing

Keep one topic focused on an explainable skill and a testable exit check. Update the editorial source in `scripts/build_curriculum.py`, rebuild, and commit the regenerated Markdown/catalog alongside the source change. Preserve inherited source attribution.

Use a branch and pull request for substantial changes. Run the commands in the README before proposing a change. Keep tests tied to actual contracts, failure cases and progress integrity.

Do not publish course transcripts, paid material, Boot.dev assignment copies, CS50 answers, API credentials or personal data. Mark fixtures and simulations clearly. Add an external resource only when it improves a specific learning step; retain access and verification notes.
